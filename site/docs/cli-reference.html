CLI reference

Every flag and every check haunt runs.

Usage

haunt [path] [options]

path defaults to the current directory.

Flags

FlagEffect
--projects <dir>Claude Code transcripts directory (default: ~/.claude/projects)
--usage-file <file>a .usage.json sidecar ({skill: {use_count}}), for runtimes that keep one instead of transcripts
--jsonmachine-readable output, for scripts and CI
--fail-on-ghostsnon-zero exit when any skill has zero real invocations

Checks

CheckSourceWhat it finds
ghost-skilltranscriptsinstalled, zero invocations in your session history
hallucinated-invocationtranscriptsinvoked by name, no matching SKILL.md exists
broken-referencestatica relative link in a skill body that doesn't resolve
duplicate-namestatictwo SKILL.md files resolve to the same skill name
missing-descriptionstaticfrontmatter has no description at all
thin-descriptionstaticdescription too short for an agent to route on

Exit codes

  • 0 - no errors (ghosts allowed unless --fail-on-ghosts is set)
  • 1 - at least one error-level finding, or ghosts found with --fail-on-ghosts
  • 2 - the given path doesn't exist
