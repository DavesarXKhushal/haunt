Quickstart

Install haunt and run your first audit in under a minute.

Install

pip install haunt

Or run it with no install at all:

uvx haunt /path/to/skills

Run it

haunt .claude/skills

That scans every SKILL.md under the given directory, reads your Claude Code session transcripts from ~/.claude/projects, and prints every finding: broken references, duplicate names, thin descriptions, and skills that have never been invoked.

No telemetry under ~/.claude/projects? Some agent runtimes keep their own usage sidecar instead. Point haunt at it directly with --usage-file, documented on the CLI reference page.

Read the output

Each finding carries a level and a code:

  • error - something is actually broken: a dead link, a duplicate name, a missing description, or an invocation of a skill that no longer exists.
  • warn - a ghost skill, or a description too thin for an agent to route on reliably. Worth a look, not necessarily a bug.

Wire it into CI

- name: Audit skills
  run: uvx haunt .claude/skills --fail-on-ghosts

--fail-on-ghosts makes the whole run exit non-zero the moment any installed skill has zero real invocations, so a dead skill gets caught in review instead of sitting in the tree for months.
